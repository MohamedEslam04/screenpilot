الترجمة والـ timeline

اكتب ملفات ترجمة بعدة لغات من ملف timeline الخاص بفيديو مصيَّر دون تصيير جديد، وأضفها كمسارات منفصلة، وتحقق من أن الترجمة تقع على الصوت.

منصات مثل YouTube وLinkedIn وVimeo تقبل ملفات الترجمة، والفيديو الموجّه لعدة دول يحتاج ملفًا لكل لغة. يصنع ScreenPilot هذه الملفات من ملف timeline الذي يكتبه كل تصيير، فلا تحتاج لغة جديدة إلى تصيير جديد. وهو لا يترجم شيئًا: أنت (أو تطبيقك الذكي) تكتب الترجمات، وScreenPilot يضعها في أوقاتها الصحيحة.

ملف الـ timeline#

كل render وكل sequence يكتب <video>.timeline.json بجوار الفيديو. يسرد متى يظهر كل سطر تعليق صوتي وكل بطاقة عنوان، بثواني الخرج.

{
  "version": 1,
  "duration": 74.2,
  "items": [
    { "kind": "narration", "id": "open", "start": 1.2, "end": 4.9, "text": "We open the settings." },
    { "kind": "card", "start": 12, "end": 14.5, "text": "Step two\nThe settings page" }
  ]
}
  • قيمة kind هي narration (سطر منطوق) أو card (بطاقة المقدمة أو بطاقة فصل؛ وtext هو عنوانها ثم عنوانها الفرعي في سطر ثانٍ) أو outro. أما البطاقات المرسومة من بيانات (بطاقات من بيانات) فلا تُسرد.
  • الحقل id لعنصر التعليق هو id السطر في الـ storyboard. وإن لم يكن للسطر id فهو موضعه بدءًا من 0.
  • الـ sequence يكتب timeline واحدًا للفيديو المجموع. ويحتفظ كل جزء بـ timeline خاص به بجوار part.mp4، فتُحسب الأجزاء المعاد استخدامها من الكاش أيضًا. وفي الـ sequence يحمل العنصر أيضًا part (رقم الجزء) وchapter (اسم مجلد storyboard الجزء).
  • تذكر نتيجة التصيير أو الـ sequence الملف تحت timeline.
إذا اختلفت مدة الـ timeline عن مدة فيديوه بأكثر من 0.25 ثانية فهو قديم، مثلًا بعد أن قصصت الفيديو يدويًا. كل أمر يقرؤه يتوقف بخطأ يذكر اسم الملف.

سمِّ أسطر التعليق الصوتي#

تُطابَق الترجمة مع السطر عبر id الخاص به. أعطِ كل سطر تعليق id قصيرًا وفريدًا. الأسطر التي بلا id تُطابَق بموضعها بدءًا من 0، وهذا ينكسر عندما تُدخل سطرًا في الوسط.

"narration": [
  { "id": "open", "at": 1, "text": "We open the settings." },
  { "id": "save", "at": 6, "text": "Then we save." }
]

تكرار الـ id يجعل المطابقة ملتبسة، فأبقِ القيم فريدة.

ملفات الترجمة#

ملف الترجمة JSON عادي تكتبه أنت. لـ storyboard واحد يربط الـ id (أو الموضع) بالسطر المترجم:

{ "open": "Abrimos los ajustes.", "save": "Guardamos." }

أما للـ sequence فالمفاتيح هي الفصول، أي أسماء مجلدات storyboards الأجزاء. يحمل الفصل إما مصفوفة فيها سطر واحد بالضبط لكل سطر تعليق في ذلك الفصل، وإما كائنًا مفتاحه الـ id:

{ "setup": ["Abrimos los ajustes.", "Guardamos."], "ops": { "done": "Listo." } }
  • السطر الذي لا ترجمة له خطأ يذكر الـ id الخاص به.
  • مصفوفة بعدد أسطر خاطئ خطأ يذكر الفصل والعددين.
  • مفتاح لا يطابق شيئًا مجرد تحذير.

تُقرأ مسارات ملفات الترجمة من المجلد الذي تشغّل فيه الأمر.

ملفات الترجمة وقت التصيير#

أضف --subtitle-lang إلى render أو sequence. يقبل قائمة مفصولة بفواصل. الرمز وحده (ar) يستخدم أسطر الفيديو نفسه. وcode=file (مثل en=en.json) يستخدم ملف ترجمة.

screenpilot render demo.json --subtitle-lang ar,en=en.json,es=es.json
screenpilot sequence all.json -q delivery --subtitle-lang ar,en=en.json,es=es.json --subtitles srt,vtt
  • الملفات هي <video>.<code>.srt و<video>.<code>.vtt، مثل all.ar.srt. الخيار --subtitles يختار الصيغ (srt أو vtt أو كلتاهما). ومع --subtitle-lang بلا --subtitles تُكتب الصيغتان.
  • الخيار --subtitle-chars <n> يضبط عدد الأحرف في سطر الترجمة. الافتراضي 42.
  • بلا --subtitle-lang يكتب render --subtitles الملفين العاديين <video>.srt و.vtt تمامًا كما كان.
  • عبر MCP تقبل الأداتان render وsequence_render الحقول languages (مثل {"ar": "auto", "en": "en.json"} حيث auto تعني أسطر الفيديو نفسه) وsubtitles وsubtitle_chars.

تُقرأ ملفات الترجمة وتُفحص قبل بدء التصيير، فيظهر الخطأ المطبعي في ثوانٍ لا بعد تصيير طويل.

ترجمة لفيديو مصيَّر سابقًا#

الأمر screenpilot subs <video> يقرأ <video>.timeline.json ويكتب ملفات الترجمة. لا يصيّر شيئًا، فإضافة لغة لاحقًا تستغرق ثانية.

screenpilot subs demo.mp4 --lang ar,en=en.json --formats srt,vtt
الخياروظيفته
--lang <list>اللغات، كما في --subtitle-lang. بدونه يُكتب ملفان عاديان <video>.srt و.vtt.
--formats <list>srt أو vtt أو srt,vtt. الافتراضي srt,vtt.
--chars <n>عدد الأحرف في سطر الترجمة. الافتراضي 42.
--join <list>لفيديو جمعته خارج ScreenPilot: ملفات timeline أجزائه بالترتيب (a.timeline.json,b.timeline.json) بدل <video>.timeline.json.
--transition <s>مع --join: عدد الثواني التي يتراكب فيها كل جزء مع السابق. الافتراضي 0، أي قطع مباشر.
--transition-type <type>مع --join و--transition: crossfade (الافتراضي) أو fade-black أو wipe-left وهكذا. التراكب واحد في كلها.
--muxيضيف الملفات أيضًا إلى الفيديو كمسارات منفصلة. انظر أدناه.

أداة MCP هي subs (المدخلات video وlanguages وformats وsubtitle_chars وjoin وtransition وtransition_type وmux). مع --join تُركَّب الأجزاء بالحساب نفسه الذي يستخدمه sequence: تراكب الانتقال لا يتجاوز نصف طول أي من الجزأين.

مسارات ترجمة منفصلة داخل الفيديو#

الخيار --mux (في MCP: mux: true) يضيف ملفات الترجمة إلى نسخة من الفيديو مع تحديد اللغة لكل مسار، فيعرض المشغّل قائمة لغات. النسخة هي <video>.subs.mp4 (بامتداد الفيديو نفسه). لا يُعاد ترميز شيء، وملفك الأصلي لا يُمَس. صيغة المسار mov_text لملفات mp4 وmov، وwebvtt لملفات mkv وwebm.

screenpilot subs all.mp4 --lang ar,en=en.json,es=es.json --mux
# يكتب all.ar.srt وall.en.srt وall.es.srt (و.vtt) وall.subs.mp4 بثلاثة مسارات لغات

كيف تُقسَّم الترجمات#

كل ملفات الترجمة تتبع مجموعة قواعد واحدة:

  • سطران كحد أقصى في كل ترجمة، نحو 42 حرفًا في السطر. يكسر السطر عند المسافات فقط، فتبقى الكلمة الطويلة كاملة.
  • سطر التعليق الأطول يصبح عدة ترجمات.
  • لا تتداخل ترجمة مع التالية، وتدوم كل واحدة 0.7 ثانية على الأقل متى وُجد متسع.
  • النص من اليمين إلى اليسار (العربية والعبرية) لا يُعاد ترتيبه ولا تُضاف إليه علامات اتجاه.

تحقق من أن الترجمة تقع على الصوت#

عندما يوجد <video>.timeline.json فإن screenpilot check <video> (في MCP: check_output) يقارن أيضًا زمن كل سطر تعليق بأول صوت بعده. ويحذّر من كل سطر يزيد الفرق فيه على 0.4 ثانية. الخيار --no-sync (في MCP: sync: false) يتخطى الفحص.

الموسيقى الخلفية تجعل الفيديو غير صامت أبدًا، فلا يستطيع الفحص رؤية مشكلة في فيديو فيه موسيقى.

مثال كامل، من sequence بفصلين إلى ثلاث لغات:

screenpilot sequence all.json -q delivery --subtitle-lang ar,en=en.json,es=es.json --subtitles srt,vtt
screenpilot check all.mp4 --every 8
screenpilot subs all.mp4 --lang ar,en=en.json,es=es.json --mux
