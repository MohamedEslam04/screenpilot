نزّل الملف المناسب لجهازك، وشغّل المثبّت، ثم أعد تشغيل تطبيق الذكاء الاصطناعي. كل ما يحتاجه ScreenPilot موجود داخل الملف الذي تنزّله، ولا تحتاج إلى تثبيت أي شيء آخر.

ثبّت تطبيق الذكاء الاصطناعي أولًا وافتحه مرة واحدة. يضيف مثبّت ScreenPilot نفسه إلى كل تطبيق ذكاء اصطناعي يجده. إذا ثبّتَّ تطبيقًا جديدًا لاحقًا، شغّل مثبّت ScreenPilot من جديد.

الإصدار 0.4.0، وهو الإصدار الحالي، فيه نسختا Windows وLinux فقط. رابطا Mac أعلاه لا يعملان حتى الإصدار القادم. آخر نسختين لـ Mac موجودتان في إصدار v0.2.3.

لا تعرف أي Mac لديك؟ افتح قائمة Apple واختر About This Mac. إذا ظهر "Chip: Apple M..." فهو Apple Silicon. وإذا ظهر "Processor: Intel" فهو Intel. كل الإصدارات في صفحة Releases.

Windows

  1. نزّل ScreenPilot-windows-setup.exe وانقر عليه نقرًا مزدوجًا.
  2. إذا ظهرت رسالة Windows protected your PC فانقر More info ثم Run anyway. المثبّت غير موقّع بعد.
  3. انقر Install. لا تحتاج إلى كلمة مرور المسؤول. التثبيت الأول يستغرق دقيقة أو دقيقتين لأنه ينزّل أيضًا مُخرِج الفيديو (نحو 100 ميغابايت، مرة واحدة).
  4. تعرض الصفحة الأخيرة تطبيقات الذكاء الاصطناعي التي أُضيف إليها ScreenPilot. انقر Finish.
  5. أعد تشغيل تطبيق الذكاء الاصطناعي. أغلقه تمامًا ثم افتحه من جديد. في Claude Desktop انقر بزر الفأرة الأيمن على أيقونته قرب الساعة واختر Quit.

إذا سألك برنامج مكافحة الفيروسات عن ScreenPilot فاسمح له. يراقب ScreenPilot نقرات الفأرة أثناء التسجيل ليكبّر عليها.

طرق أخرى للتثبيت على Windows

  • Claude Desktop فقط: انقر نقرًا مزدوجًا على ScreenPilot-windows.mcpb ثم انقر Install داخل Claude.
  • لا تستطيع تشغيل المثبّتات: نزّل ScreenPilot-windows.zip وانقر عليه بالزر الأيمن واختر Extract All، ثم افتح المجلد وانقر نقرًا مزدوجًا على ScreenPilot Setup.cmd.

macOS

  1. نزّل ملف zip المناسب لجهازك وانقر عليه نقرًا مزدوجًا. ستحصل على مجلد ScreenPilot.
  2. افتح المجلد وانقر نقرًا مزدوجًا على Install ScreenPilot.command.
  3. في أول مرة يقول macOS إنه لا يستطيع التحقق من المطوّر. انقر Done. افتح System Settings ثم Privacy & Security وانزل إلى الأسفل وانقر Open Anyway بجانب "Install ScreenPilot.command" ثم أكّد. لم توثّق Apple تطبيق ScreenPilot بعد.
  4. تعرض نافذة Terminal ما جرى تثبيته. اضغط Enter لإغلاقها. يمكنك الآن حذف المجلد الذي نزّلته.
  5. أعد تشغيل تطبيق الذكاء الاصطناعي (Cmd+Q ثم افتحه من جديد).

أذونات macOS

في أول مرة تطلب فيها تسجيلًا، يطلب منك macOS أن تسمح لـتطبيق الذكاء الاصطناعي (Claude أو Cursor أو Terminal) وليس لـ ScreenPilot نفسه. افتح System Settings ثم Privacy & Security وفعّل تطبيق الذكاء الاصطناعي في هذه القوائم:

  • Screen & System Audio Recording: لازم للتسجيل.
  • Accessibility: لازم حين يستخدم الذكاء الاصطناعي تطبيقاتك نيابةً عنك (الفأرة ولوحة المفاتيح).
  • Input Monitoring: اختياري. يتيح للتسجيلات أن تكبّر على نقراتك أنت.

ثم أغلق التطبيق وافتحه من جديد. حين ينقص إذن، يفتح ScreenPilot صفحة الإعدادات الصحيحة، ويذكر الخطأ اسم التطبيق الذي يجب السماح له.

Claude Desktop فقط: انقر نقرًا مزدوجًا على ScreenPilot-macos-arm64.mcpb (لـ Intel: ScreenPilot-macos-x64.mcpb) ثم انقر Install داخل Claude. ينطبق على هذين الملفين التنبيه نفسه عن غياب نسخ Mac.

Linux

  1. نزّل ScreenPilot-linux.tar.gz وانقر عليه بالزر الأيمن واختر Extract Here. ستحصل على مجلد ScreenPilot.
  2. افتح المجلد وانقر نقرًا مزدوجًا على install.sh. اختر Run أو Run in Terminal إذا سُئلت. تعرض نافذة طرفية ما يحدث. أو افتح طرفية داخل المجلد وشغّل ./install.sh.
  3. التسجيل المدمج على سطوح مكتب Wayland يحتاج إلى بعض حزم النظام (GStreamer). إذا كانت ناقصة، يعرض المثبّت الأمر الدقيق لتوزيعتك (Fedora أو Ubuntu أو Debian أو Mint أو Arch أو openSUSE) ويسألك هل يشغّله. اكتب y ثم كلمة المرور. يمكنك تخطي هذه الخطوة وتنفيذها لاحقًا.
  4. أعد تشغيل تطبيق الذكاء الاصطناعي.
  5. في أول مرة تسجّل فيها، أو تدع الذكاء الاصطناعي يستخدم سطح مكتبك، يطلب سطح المكتب إذنًا مرة واحدة بمشاركة الشاشة أو التحكم عن بُعد. اسمح به.
لا تشغّل المثبّت بـ sudo. يثبّت لمستخدمك فقط ولا يحتاج إلى صلاحيات المسؤول. إذا شغّلته بـ sudo يتوقف ويطلب منك إعادة تشغيله بحسابك العادي.

ما يعمل يعتمد على سطح المكتب. راجع دعم المنصات للجدول الكامل.

تأكد أنه يعمل

  1. أغلق تطبيق الذكاء الاصطناعي تمامًا ثم افتحه من جديد.
  2. قل له: "Run the ScreenPilot doctor." يعرض حالة المسجّل والأذونات والأصوات ومحرّك الفيديو، ويشرح كيف تصلح الناقص. إذا ظهر لك هذا التقرير فـ ScreenPilot متصل.
  3. للتأكد مرة أخرى، ابحث عن screenpilot في قائمة أدوات التطبيق أو إعدادات MCP. في Claude Code اكتب /mcp (أو claude mcp list في الطرفية)، ويجب أن تظهر كلمة Connected.
  4. جرّب طلبًا حقيقيًا: "Take a screenshot of my screen." قد يطلب سطح المكتب في المرة الأولى السماح بمشاركة الشاشة. اسمح له.

لم يظهر شيء؟ راجع إذا حدثت مشكلة.

ماذا يفعل المثبّت

  • ينسخ ScreenPilot إلى مجلد المستخدم: %LOCALAPPDATA%\ScreenPilot على Windows، و~/Library/Application Support/ScreenPilot على macOS، و~/.local/share/screenpilot على Linux.
  • ينشئ مجلد الإخراج لفيديوهاتك داخل مجلد الفيديو.
  • يضيف ScreenPilot إلى كل تطبيق ذكاء اصطناعي يجده، ويحفظ نسخة احتياطية من ملف إعداداته قبل التعديل. تبقى بقية الإدخالات والتعليقات كما هي.
  • ينزّل مُخرِج الفيديو ويختبره، في أول مرة فقط.

التطبيقات التي يُضاف إليها

يضيف المثبّت ScreenPilot إلى كل واحد من هذه التطبيقات يجده:

  • Claude Desktop (ومنه نسخة Microsoft Store) وClaude Code. ومع Claude Code يثبّت أيضًا مهارة ScreenPilot.
  • Codex وOpenCode وGemini CLI وQwen Code وGitHub Copilot CLI وAmazon Q وGoose وWarp.
  • Cursor وWindsurf وDevin Desktop وAntigravity وKiro وZed وLM Studio.
  • VS Code وVS Code Insiders وVSCodium، مع إضافتَي Cline وRoo Code.

JetBrains AI Assistant ليس له ملف إعدادات. بعد التثبيت استخدم زر Import from Claude فيه.

لتجنّب سؤال الإذن في كل مرة يستخدم فيها Claude Code أداة من ScreenPilot، شغّل setup مع --allow-tools. اقرأ صفحة الأمان قبل ذلك.

إضافته إلى تطبيق آخر يدويًا

يعمل أي تطبيق يدعم خوادم MCP. هذا الأمر يطبع الإعدادات التي تنسخها:

  • Windows (Command Prompt): "%LOCALAPPDATA%\ScreenPilot\bin\node.exe" "%LOCALAPPDATA%\ScreenPilot\dist\cli.js" setup --print
  • macOS: ~/Library/Application\ Support/ScreenPilot/bin/node ~/Library/Application\ Support/ScreenPilot/dist/cli.js setup --print
  • Linux: ~/.local/share/screenpilot/bin/node ~/.local/share/screenpilot/dist/cli.js setup --print

يطبع إدخال mcpServers قياسيًا (الأمر والوسائط والبيئة) تقبله معظم التطبيقات. الصقه في إعدادات MCP في التطبيق ثم أعد تشغيل التطبيق.

لمعرفة التطبيقات التي يعرفها setup وهل كل منها مثبّت، شغّل الأمر نفسه مع setup --list بدلًا من setup --print.

التحديث والإزالة

التحديث: نزّل المثبّت الجديد وشغّله. إذا كان تطبيق ذكاء اصطناعي مفتوحًا، يطلب منك المثبّت إغلاقه أولًا.

  • Windows: افتح Settings ثم Apps ثم Installed apps، وابحث عن ScreenPilot واختر Uninstall. يزيل أيضًا ScreenPilot من تطبيقات الذكاء الاصطناعي.
  • macOS: انقر نقرًا مزدوجًا على Uninstall ScreenPilot.command في المجلد الذي نزّلته. نزّله من جديد إذا حذفته.
  • Linux: شغّل ./uninstall.sh في المجلد الذي نزّلته.

الإزالة تُخرج ScreenPilot من تطبيقات الذكاء الاصطناعي. تبقى فيديوهاتك في مكانها.

إذا حدثت مشكلة

  • التطبيق لا يعرف ScreenPilot. أغلق تطبيق الذكاء الاصطناعي تمامًا وافتحه من جديد. لم يتغير شيء؟ شغّل المثبّت مرة أخرى. يعرض لك التطبيقات التي أضاف ScreenPilot إليها.
  • "No AI tool found". ثبّت تطبيق الذكاء الاصطناعي وافتحه مرة واحدة، ثم شغّل مثبّت ScreenPilot من جديد.
  • المثبّت يطلب إغلاق تطبيقات الذكاء الاصطناعي. تطبيق مفتوح يستخدم نسخة ScreenPilot القديمة. أغلقه وانقر Retry.
  • "Video renderer: not ready". التنزيل لمرة واحدة يحتاج إلى الإنترنت. لا شيء عليك فعله: أول فيديو سينزّله.
  • التسجيل أو التحكم بالفأرة لا يعمل على Mac. اسمح لتطبيق الذكاء الاصطناعي في Screen & System Audio Recording وفي Accessibility، ثم أغلقه وافتحه من جديد.

شغّل الـ doctor

لفحص كل شيء دفعة واحدة، قل لتطبيق الذكاء الاصطناعي: "Run the ScreenPilot doctor." يفحص المسجّل والأذونات والأصوات وغيرها، ويشرح كيف تصلح الناقص. ويستطيع المطورون تشغيل screenpilot doctor في الطرفية. إجابات أخرى في الأسئلة الشائعة.
